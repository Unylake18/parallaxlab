Para o arsenal de sólidos 3D (`experimentos/blender/arsenal/`), o padrão visual vigente é o da série Lei de Gauss (`yt_0001`/`yt_0002`) e dos sólidos já aprovados, registrado em `arsenal/estilo.json`: ciano só para campo, azul `#267BFF` (preenchimento) e `#7FB2FF` (contorno) para fontes físicas, violeta `#9C8CFF` tracejado/translúcido para construções matemáticas, branco para o neutro.

**Why:** o usuário disse (2026-10-07) "não se importe muito com os vídeos muito antigos, vamos seguir conforme Lei de Gauss e os outros que fizemos". Vídeos antigos usam gramáticas diferentes (ex.: `vid_0009` usa verde para corrente e magenta para contorno amperiano; `vid_0014` usa ciano para eixo) e não devem ditar o arsenal.

**How to apply:** ao desenhar um sólido novo (Ampère, Mecânica, Cálculo), não pare para reconciliar com a cor dos vídeos antigos nem pergunte por isso; use `estilo.json`. Contorno amperiano = mesma família violeta tracejada da gaussiana. Veja [[projeto-yt0002-gauss]] para o sistema visual do 2D.

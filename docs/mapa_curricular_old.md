# Mapa curricular editorial — Parallax Lab

**Status:** arquitetura editorial aprovada para orientar a biblioteca de vídeos longos.\
**Escopo atual:** Física I–IV e Cálculo I–IV.\
**Futuro planejado:** Álgebra Linear, Equações Diferenciais e outras disciplinas de base.\
**Importante:** este documento **não é um calendário de publicação** e não obriga produzir os vídeos na ordem abaixo.

---

## 1. Para que serve este mapa

O Parallax Lab pode publicar vídeos em ordem editorial, aproveitando os melhores temas para descoberta e retenção, sem perder coerência acadêmica.

A biblioteca é organizada depois por:

**curso/eixo → macroassunto → módulo → vídeo autossuficiente**

A ordem de publicação pode ser diferente da ordem de estudo.

O mapa existe para evitar dois extremos:

1. transformar o canal cedo demais num curso linear rígido;
2. acumular dezenas de vídeos excelentes, porém sem arquitetura curricular.

---

## 2. Coordenadas obrigatórias de um vídeo longo

Antes de entrar em produção, todo vídeo longo deve conseguir responder:

- **curso/eixo:** Física I, Física II, Física III, Física IV, Cálculo I, II, III ou IV;
- **macroassunto:** bloco conceitual amplo;
- **módulo:** unidade didática mais específica;
- **natureza:** `teoria_visual`, `derivacao_aplicada` ou `exercicio_resolvido`;
- **pergunta central:** uma pergunta que o vídeo realmente responde;
- **pré-requisitos:** somente os necessários;
- **payoff principal:** o que o aluno consegue enxergar/compreender ao final.

A taxonomia é editorial. Não precisa coincidir palavra por palavra com a grade de uma universidade específica.

---

## 3. Como um módulo amadurece

Não é obrigatório completar um módulo antes de publicar outro.

Como alvo de biblioteca, um módulo importante pode amadurecer com algo próximo de:

1. **vídeo-âncora (`teoria_visual`)** — estabelece o conceito e a representação visual principal;
2. **derivação ou aplicação (`derivacao_aplicada`)** — mostra de onde vem uma relação importante ou como ela se conecta a um fenômeno;
3. **problema forte (`exercicio_resolvido`)** — usa o conceito em uma questão universitária não trivial e extrai algo além da resposta imediata.

Nem todo módulo exige exatamente três vídeos. É uma estrutura de referência, não uma cota.

# PARTE E — REGRAS EDITORIAIS

# 17. Ordem de publicação não é ordem curricular

Não numerar vídeos públicos como se a publicação precisasse seguir o currículo.

O vídeo publicado hoje pode ocupar futuramente a posição 7 de uma playlist.

A prioridade para escolher a próxima pauta é a combinação de:

1. qualidade didática;
2. potencial visual;
3. rigor;
4. capacidade de funcionar sozinho;
5. valor para a biblioteca futura;
6. interesse observado do público;
7. custo de produção.

# 18. Como escolher a próxima pauta longa

Antes de aprovar um tema, perguntar:

- Em qual curso/eixo ele entra?
- Em qual macroassunto?
- Em qual módulo?
- É âncora conceitual, derivação/aplicação ou exercício?
- Funciona sozinho?
- O que ele acrescenta à biblioteca?
- Existe um payoff visual forte?
- Ele cria uma ponte útil para outro vídeo futuro?
- O assunto justifica 8–10 minutos sem enchimento?
- É possível representar a ideia com Manim de maneira melhor que uma aula tradicional?

Se as respostas forem fracas, a pauta pode ser boa para curto e ruim para longo.

# 19. Regra para exercícios específicos

Exercícios resolvidos longos são desejáveis.

Eles não precisam introduzir um macroassunto, mas devem ter endereço curricular claro.

Exemplo:

**Mecânica → Cinemática → Lançamentos → exercício de alcance ótimo a partir de uma altura.**

O exercício pode ser publicado antes das aulas teóricas relacionadas. Depois ele entra na posição didática correta da playlist.

Para inaugurar um módulo importante, dar preferência a um vídeo-âncora conceitual quando isso produzir uma biblioteca mais coerente.

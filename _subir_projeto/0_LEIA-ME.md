## Criar o Projeto (claude.ai: Projects → New project · ChatGPT: Projects → New project)

1. Nome: **Parallax Lab**.
2. **Instruções:** cole o conteúdo de `1_INSTRUCOES_DO_PROJETO.txt` (claude.ai: "Set project instructions"; ChatGPT: "Instructions").
3. **Fontes/arquivos:** suba **todos** os arquivos da pasta `fontes/` (12 arquivos, ~210 KB).
4. **Chats:** crie conforme `2_CHATS_E_PROMPTS.md` (não precisa abrir todos de uma vez).

## Atualizar um Projeto que já existe (o do GPT)

- Substitua as cópias antigas destes arquivos: `estado_atual.md` (reconciliado em 24/10), `AGENTS.md`, `formatos.md` e `roteiro_voz_elevenlabs_v4.md` (ganharam o link para o padrão novo).
- Novo: `padrao_video_longo.md`.
- Se ainda não estiverem lá: `indice_producao.md`, `cobertura.md`, `mapa_curricular.md`, `padroes_producao.md`, `identidade_visual.md`.
- Troque as instruções pelas de `1_INSTRUCOES_DO_PROJETO.txt`. Elas são as mesmas para os dois Projetos e incluem o padrão do longo e as regras da fala.
- O `START_HERE.md`, citado no guia_mestre, não foi incluído: parou em 01/10 (fala só dos vid_0001–0003) e o `estado_atual.md` cobre o mesmo papel. Se ele estiver no Projeto do GPT, tire, para não confundir.
